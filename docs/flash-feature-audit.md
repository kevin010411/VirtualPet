# project_18 功能 Flash 占用分析

## 結論摘要

`project_18` 的量測基線為 **61,656 / 65,536 bytes（94.08%）**，剩餘
3,880 bytes。以目前可獨立編譯切換的功能來看，猜物遊戲與外觀選擇的
邊際 Flash 占用最大。

## 量測方式與限制

- 目標：STM32F103C8T6（64 KiB Flash）。
- 組態：`platformio.ini` 的 `project_18`。
- 方法：以基線編譯為對照，一次只變更一個 `ENABLE_*` 功能閘後重新編譯，
  取 ELF 的 Flash 大小差額。
- 差額是該組態下的**邊際**占用，不能相加；LTO 與共用程式碼會使多項功能
  共用部分實作。
- 未具有獨立功能閘的核心功能（SD、渲染、寵物邏輯與儲存等）無法在不改變
  架構的前提下，誠實拆為單一功能占比。

## 相依關係與判讀

`ENABLE_FIRST_START_ANIMATION` 依賴 `ENABLE_STARTUP_ANIMATION`。兩者同時
關閉時，Flash 會減少 580 B；表中的兩項個別差額應只用於理解目前組態，
不應與其他列加總。

「猜物後玩家選結果」的 -12 B 屬於連結器與最佳化造成的微小淨變化，不表示
該功能沒有實作成本。

## 驗證狀態

本文件記錄編譯期 Flash 量測，不代表 SD 資源、裝置行為、RAM 峰值或硬體
實機流程已驗證。量測時所有暫時設定均已還原。
