## 共通工程工作

上述每個被選定的功能都需要確認前端設定、Backend validation／export、SD runtime 表與韌體執行是否變更。新增按鈕種類、選單、訊息、派生值、遊戲或長期存檔時，不只檢查欄位，還要確認執行語意及舊資料處理。

目前 `runtime.bin` 使用 v9 契約；不存在把這份 HTML／WASM 直接匯入 STM32 的既有入口。來源是 ESP32-C3 模擬器，不能視為本平台的可執行素材包。

完整狀態至少含三能力、三類訓練計數、額度、性別、軍階、軍種、部隊、役期及流程旗標。不能先假設都放進 Pet Stats：當前預設編譯上限6個 Stats，Pet save 的既有陣列為8槽；需逐層確認容量與責任。当前 `project_29` 只載入4動畫、命名動畫容量0，不應直接當作兵兵完整profile。容量提高的Flash／RAM成本尚未量測。

完整畫面若要求像素位置還原，也需要單獨決策：現有版面是16px格線且不可重疊，而原版區域與六格按鈕切點並非全為16的倍數。保留來源圖片尺寸不等於現有版面已能還原原位置；本次仍遵守原素材不縮放的要求。

硬體低電量、熄燈、休眠與按鍵喚醒已有基礎。需補與遊戲日／輸入／存檔的整合驗收，不能把這些全部當新功能，也不能因原模擬器電池滑桿可用就當實機已通過。
