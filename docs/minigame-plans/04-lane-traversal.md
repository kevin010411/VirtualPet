# 路線選擇／地雷設計提案

2026-10-11 提案的精簡版，尚未實作／驗收；共通输入、時計、保存、profile 與責任見 [共通計畫](README.md)。

## 創作者與容量

創作者設定路線／步數、手動列遮罩或隨機障礙數、持續／短暫提示、素材與安全／障礙效果。
提案容量：2–3 路（預設 3）、1–32 步（預設 10）、每列至多路線數−1 障礙，
觀看 300–5000 ms、作答 1000–15000 ms、回饋 100–1000 ms。
兵兵三路十步：安全一步體力 +5、踩雷 −10；原版雷數／提示時間待確認。

## 韌體狀態與契約

`LaneTraversal`：PrepareRow → Preview／AwaitRelease → Choosing → ResolveStep → Feedback → NextRow／Completed → Result。
起始選中間（二路選左），下一列沿用選中路線；左右邊界夾住、不環繞，確定消耗一列。
判定用列遮罩，與像素碰撞無關。每步等待原子效果提交成功才前進，踩雷仍消耗一步。
deadline 算逾時、不提交本列；退出保留已提交步驟。整場地圖只生成一次，重畫不重抽。
固定至多 32 個列遮罩，結束畫面不再重複給整場效果。

Web 穩定 ID 在匯出時投影為固定索引，設定、素材角色、結果與 effects 分開引用。
新增 wire 格式／版本先在 Web 定案；容量仍是提案，以目標 linked build 決定。
