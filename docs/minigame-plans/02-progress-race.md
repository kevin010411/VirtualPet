2026-10-11 提案的精簡版，尚未實作／驗收；共通输入、時計、保存、profile 與責任見 [共通計畫](README.md)。

## 創作者與容量

創作者選對手競速或倒數模式，設定進度、速度／期限、過快處罰、單一反應事件、素材與三種終局。
提案容量：目標／按次增量 1–1000、整場 5–120 秒、最小間隔 100–1000 ms、
事件間隔 1000–15000 ms、反應 300–5000 ms、暫停 200–5000 ms、失誤上限 1–10（預設 4）。
兵兵完成：體力 +30／戰技 +20；對手勝：體力 +10；四次失誤：體力 −35／戰技 −10。

## 韌體狀態與契約

`ProgressRace`：Prepare → AwaitRelease → Running ↔ EventPending／PenaltyPause → Completed → Result。
確定推進，事件期只接受指定解除鍵；過快、錯鍵或逾時各事件最多一次失誤。
对手與總時限在暫停／事件中繼續，事件倒數在處罰中停止；進度依時間而非 tick 次數。
同時完成的提案次序為失誤上限、玩家完成、對手完成、整場逾時；精確 deadline 算逾時。
自然終局一次結算，退出无效果。隨機來源由 controller 注入。

Web 穩定 ID 在匯出時投影為固定索引，設定、素材角色、結果與 effects 分開引用。
新增 wire 格式／版本先在 Web 定案；容量仍是提案，以目標 linked build 決定。
