## 創作者與容量

創作者建立三物品、選取／禁止操作提示、題數、期限、洗牌比例、素材與答對數結果表。
提案容量：1–20 題（預設 10）、固定三選項、500–10000 ms 作答、100–1000 ms 回饋、至多 21 結果區間。
禁止操作題數為 `(題數 × 比例 + 50) / 100`，固定題型表洗牌；目標可重複。
兵兵十題智力效果 0..10 → −20、−20、−15、−10、0、+10、+15、+25、+30、+40、+50。

## 韌體狀態與契約

`InstructionResponse`：PrepareQuestion → AwaitRelease → Answering → Feedback → NextQuestion／Completed → Result。
左／確定／右對應位置，物品 ID 不隨位置變。禁止操作題全期限不按才算正確；
選擇題只接受第一次單鍵，精確 deadline 算逾時，多鍵不能拆成多個答案。
保留固定題型位元表、三位置索引與計數；整場完成一次結算，取消無效果。

Web 穩定 ID 在匯出時投影為固定索引，設定、素材角色、結果與 effects 分開引用。
新增 wire 格式／版本先在 Web 定案；容量仍是提案，以目標 linked build 決定。
