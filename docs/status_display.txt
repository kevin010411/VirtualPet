# status_display.txt

Status display is selected by the compile-time APP_STATUS_MODE. The mode name
in this file must match the compiled mode. Firmware only parses the row for the
compiled mode; other rows are ignored.

If the compiled mode cannot find the required animation or config row, the TFT
shows:

status not found

Formats:

direct|Status|
composite_health|auto|
single_meter|Animation|source
random_meters|AnimationA,AnimationB,AnimationC|sourceA,sourceB,sourceC
triple_meter|Animation|sourceA,sourceB,sourceC

Mode mapping:

STATUS_MODE_DIRECT           -> direct
STATUS_MODE_SINGLE_METER     -> single_meter
STATUS_MODE_RANDOM_METERS    -> random_meters
STATUS_MODE_COMPOSITE_HEALTH -> composite_health
STATUS_MODE_TRIPLE_METER     -> triple_meter

direct and composite_health do not require this file at runtime.

Supported sources include:

age
hunger
satiety
mood
clean
env
sick
status
healthy_days
stage_healthy_days
stage_progress
custom0..custom7

Aliases from /state_schema.txt can also be used, for example money, fatigue,
alcohol, or intimacy.

DipsyHo example:

triple_meter|StatusAge|stage_progress,satiety,mood
